## Descrição

Projeto desenvolvido em C# utilizando aplicação Console.

O programa permite informar o nome completo e a data de nascimento do usuário, calcula a idade com base na data atual do sistema e informa se a pessoa é maior de idade e se pode realizar o procedimento para obter a Carteira Nacional de Habilitação.

## Tecnologias

- C#
- .NET
- Visual Studio 2022

## Funcionalidades

- Entrada do nome completo
- Entrada da data de nascimento
- Validação de data inválida
- Validação de data futura
- Cálculo da idade
- Verificação de maioridade
- Verificação para habilitação
- Uso de struct
